Kiến trúc mạng RoomSplit trên AWS

VPC lab cho tài khoản free: 2 AZ × 3 tầng subnet. Phần mạng miễn phí và được giữ lâu dài. NAT, EC2 và EICE chỉ bật theo từng giai đoạn để thí nghiệm, sau đó xóa.

  • RegionR3 · us-east-1
  • TopologyB · 2 AZ × 3 tầng
  • NATN1 · NAT Gateway bật tạm
  • NACLL2 · riêng tầng data
  • Truy cậpS3 · EC2 Instance Connect Endpoint
  • Công cụT1 · Console trước
Xem theo giai đoạn:

Đang hiện mọi thành phần của lab. Khung nét đứt xám là chỗ chừa sẵn cho bài deploy sau này.

Bốn luồng cần quan sát

  • 1
    Bạn ↔ RoomSplit trên EC2 · GĐ 2

    HTTP cổng 80 đi qua IGW theo cả hai chiều, vì rt-public có 0.0.0.0/0 → igw và máy có IP public. SG web chỉ nhận từ IP của bạn. Trong máy chạy mysql + redis + api bằng docker compose.

  • 2
    test-private → NAT → Internet · GĐ 3

    Chỉ đi ra được. Trước khi có NAT thì lệnh curl bị timeout. Sau khi thêm route tới nat-a, IP trả về là EIP của NAT. Từ ngoài vẫn không vào được máy này.

  • 3
    Bạn → EICE → máy private · GĐ 2

    SSH cổng 22 qua API của AWS, có kiểm tra quyền IAM. Không đi qua IGW, không cần IP public hay NAT.

  • 4
    app → data :3306 · GĐ 4

    Phải qua cả SG db (stateful) lẫn nacl-data (stateless). Thử bằng curl -m 5 http://<ip-test-db>:3306. Xóa rule outbound 1024–65535 của NACL thì kết nối bị timeout.

Giá tham khảo ở us-east-1: phần mạng 0 USD; NAT Gateway khoảng 0,045 USD/giờ; EC2 t3.micro khoảng 0,0104 USD/giờ; mỗi IPv4 public 0,005 USD/giờ. Nếu dọn đúng hạn, cả lab tốn dưới 1 USD. Chi tiết và bảng ghi ID nằm trong docs/aws-lab-architecture.md của repo.
